# Terminal Pipeline Audit

This is a living audit for the terminal-link goal. It maps the reference
pipeline requirements to current NyaTerm evidence and highlights remaining
verification gaps. Do not treat this file as a completion claim; it is a
checklist for reaching one.

## Status Key

- `Verified`: current source and targeted tests prove the item.
- `Implemented`: source evidence is present, but the item still needs broader
  command/runtime verification before final completion.
- `Partial`: nyaterm intentionally implements a narrower behavior than the
  reference, or a known part is not complete.
- `Open`: not yet implemented or evidence contradicts completion.

## Environment Notes

- trzsz support currently detects and filters trigger markers, filters
  transfer-stage protocol frames and binary DATA bodies after a trigger, models
  typed action/config negotiation, can build local protocol frames, tracks
  transfer phases/events, handles remote `tsz` file/directory downloads in
  desktop by writing files into the configured download directory and reporting
  `TrzszDownload` transfer jobs, and handles remote `trz` file/directory
  uploads by prompting for local paths, feeding acknowledgements through the
  upload engine, and reporting `TrzszUpload` transfer jobs.
- Full `cargo test -p nyaterm-terminal-gpui` and desktop unit-test execution may
  require system libraries not present in every environment, currently
  `libxkbcommon-x11`. Prefer `cargo check ... --tests` unless the environment
  has the required libraries.
